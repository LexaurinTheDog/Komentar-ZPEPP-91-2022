# Komentář k zákonu č. 91/2022 Sb., o panevropském osobním penzijním produktu a o změně souvisejících zákonů (zákon o panevropském osobním penzijním produktu)

Otevřený komentář k zákonu o panevropském osobním penzijním produktu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; příslušný orgán, registrace PEPP, distributor a odborná způsobilost, postoupení smluv a změna poskytovatele, dohled, opatření k nápravě, přestupky, seznamy a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-2022-00091_2022-05-11`.
